Specialized agents for native iOS development, cross-platform mobile apps, and Swift architecture.

|------|------|-------------|
| Agent | ios-developer | Native iOS development with Swift and SwiftUI |
| Agent | mobile-developer | Cross-platform mobile development with React Native and Flutter |
| Agent | swift-expert | Swift architecture decisions, concurrency design, and platform strategy |
