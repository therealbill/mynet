# DevOps and Infrastructure

Specialized agents for deployment automation, CI/CD pipelines, performance monitoring, and metrics collection.

## Components

| Type | Name | Description |
|------|------|-------------|
| Agent | devops-automator | CI/CD pipelines, cloud infrastructure, and deployment automation |
| Agent | github-actions-expert | GitHub Actions workflows, optimization, and security |
| Agent | performance-monitor | Performance analysis, bottleneck identification, and SLO-based alerting |
| Agent | prometheus-expert | Prometheus configuration, PromQL queries, and alerting rules |
