# Utility Agents

Cross-domain utility agents for workflow orchestration, URL validation, and link inventory management.

## Components

| Type | Name | Description |
|------|------|-------------|
| Agent | episode-orchestrator | Episode-based workflow orchestration with validation and conditional routing |
| Agent | url-context-validator | URL validation for functionality and contextual appropriateness |
| Agent | url-link-extractor | Comprehensive URL extraction and cataloging from codebases |
