# Research

Specialized agents for multi-source research, academic literature review, technical analysis, synthesis, and report generation.

## Components

| Type | Name | Description |
|------|------|-------------|
| Agent | academic-researcher | Scholarly sources, peer-reviewed papers, and scientific literature |
| Agent | comprehensive-researcher | Deep multi-source research across academic, industry, news, and government sources |
| Agent | technical-researcher | Code repositories, libraries, APIs, and implementation analysis |
| Agent | research-synthesizer | Consolidates findings from multiple research agents into unified analysis |
| Agent | report-generator | Transforms research findings into polished, well-structured documents |
