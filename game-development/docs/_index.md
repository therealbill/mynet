# Game Development

Specialized agents for game design, general game development, engine-specific implementation, and 3D art production.

## Components

| Type | Name | Description |
|------|------|-------------|
| Agent | 3d-artist | 3D art and asset creation for game pipelines |
| Agent | game-designer | Game mechanics, systems balancing, and player experience |
| Agent | game-developer | General game architecture, engine selection, and performance |
| Agent | unity-game-developer | Unity-specific C# scripting, URP/HDRP, and mobile optimization |
| Agent | unreal-engine-developer | Unreal Engine C++ programming, Blueprints, and UE5 systems |
