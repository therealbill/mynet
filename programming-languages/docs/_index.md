# Programming Languages

Specialized agents for writing, reviewing, and optimizing code in specific programming languages. Each agent has deep knowledge of its language's idioms, patterns, and ecosystem.

## Components

| Type | Name | Description |
|------|------|-------------|
| Agent | cpp-pro | Modern C++ with RAII, smart pointers, templates, and concurrency |
| Agent | go-simplifier | Go code refinement for idiomaticity, clarity, and maintainability |
| Agent | javascript-pro | Modern JavaScript for Node.js and browser environments |
| Agent | typescript-pro | Advanced TypeScript type system, strict config, and type-safe APIs |
| Agent | zsh-expert | Z Shell configuration, scripting, and startup optimization |
