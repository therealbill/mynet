# Code Quality

Specialized agents for code review, test management, accessibility auditing, and architectural consistency.

## Components

| Type | Name | Description |
|------|------|-------------|
| Agent | code-reviewer | Reviews code for bugs, security, and quality |
| Agent | architect-reviewer | Reviews code for architectural consistency |
| Agent | test-writer-fixer | Writes, runs, and fixes tests |
| Agent | playwright-expert | Playwright end-to-end test automation |
| Agent | web-accessibility-checker | WCAG compliance and accessibility auditing |
